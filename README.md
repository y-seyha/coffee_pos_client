## 🚀 Getting Started
### 1. First, Clone the repository:
#### Clone Repo : git clone https://github.com/y-seyha/coffee_pos_client.git
##### Navigate to project : cd coffee_pos_client

### 2. Install dependencies:
```bash
npm install
```

### 3. 🔐 Environment Variables

Create .env file in the root directory: (.env) (**Environment variables are provided via Telegram (Yoeun Seyha)**).


### 4. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3000) with your browser to see the result.

### 5. Notes
- Make sure Node.js (v18+) is installed

- Ensure .env is properly set before running the project

- Always run on port 3001 3002 (CORS won't block)
